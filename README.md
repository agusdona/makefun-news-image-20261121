"Missiles Over Poland" — a pure-stdlib Python program that draws a one-page newspaper poster summing up the world news of Saturday 21 November 2026: Russian missiles fall on Poland (hero), Myanmar rejects the court verdict, Wall Street slides into correction, and the first Trump-Xi-Putin summit ends thin in Shenzhen, plus a ticker with COP31, the Houthi missile intercepted over Riyadh, and the UK-EU deal. Everything (5x7 bitmap font, map, charts, PNG encoder) is drawn from scratch with no external files or network, so two runs produce byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
